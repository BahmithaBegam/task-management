# Full-Stack Task Management Application

A secure and responsive full-stack task management web application built with modern cloud tools.

## 🚀 Live Links
* **Frontend (Vercel):** [https://task-management-theta-inky.vercel.app](https://task-management-theta-inky.vercel.app)
* **Backend API (Render):** [https://task-management-backend-7gqr.onrender.com](https://task-management-backend-7gqr.onrender.com)

## 🛠️ Tech Stack
* **Frontend:** React, Vite, Tailwind CSS, Vercel
* **Backend:** Node.js, Express, Render
* **Database & Auth:** Supabase (PostgreSQL & Supabase Auth)

## ✨ Features
* User Authentication (Sign Up, Sign In, Logout)
* Secure Database Integration via Supabase
* Full CRUD Operations (Create, Read, Update, Delete tasks)
* Fully responsive glassmorphism UI
